{# 3. Normalidade (premissa do teste t) #}

O teste t supõe que os d vêm de uma distribuição normal. No gráfico Q-Q, cada mês é um ponto: se os dados forem normais, os pontos ficam perto da reta.

  1. Shapiro-Wilk (H₀: os d são normais; os pesos ai vêm da tabela do teste)

    W = \dfrac{\left(\sum a_i\, d_{(i)}\right)^2}{\sum (d_i - \bar{d})^2} = {{ c.shapiro_w|tex:3 }} \qquad {{ c.shapiro_p|valor_p_tex }}

{% if c.shapiro_p is None %}Sem variação suficiente para testar.{% elif c.normal %}p ≥ 0,05: não há evidência contra a normalidade, então o teste t é adequado. O Wilcoxon, que não supõe normalidade, serve de confirmação.{% else %}p < 0,05: os d fogem da normal. Com {{ c.n }} meses o teste t fica menos confiável; vale mais o Wilcoxon, que não supõe normalidade.{% endif %}

{# 4. Teste t pareado #}

  1. Média das diferenças

    \bar{d} = \dfrac{\sum d}{n} = \dfrac{ {{ c.soma_diferencas|tex:0 }} }{ {{ c.n }} } = {{ c.media|tex:1 }}

  2. Desvio-padrão amostral das diferenças

    s_d = \sqrt{\dfrac{\sum (d - \bar{d})^2}{n - 1}} = {{ c.desvio|tex:1 }}

  3. Erro-padrão da média

    \mathrm{EP} = \dfrac{s_d}{\sqrt{n}} = \dfrac{ {{ c.desvio|tex:1 }} }{\sqrt{ {{ c.n }} }} = {{ c.erro_padrao|tex:1 }}

  4. Estatística t com {{ c.graus }} graus de liberdade (n − 1)

    t = \dfrac{\bar{d}}{\mathrm{EP}} = \dfrac{ {{ c.media|tex:1 }} }{ {{ c.erro_padrao|tex:1 }} } = \mathbf{ {{ c.t|tex:2 }} }

  5. Intervalo de 95% da queda média por mês (t_{0{,}975;\,{{ c.graus }} } = {{ c.t_critico|tex:3 }})

    \bar{d} \pm t \cdot \mathrm{EP} = \left[\, {{ c.ic_inferior|tex:0 }} \;;\; {{ c.ic_superior|tex:0 }} \,\right]

{# 2. Pearson #}

x = renda mediana (US$ mil), y = veículos por mil hab., n = {{ c.n }} condados.

  1. Médias

    \bar{x} = {{ c.media_x|tex:2 }} \qquad \bar{y} = {{ c.media_y|tex:2 }}

  2. Somas dos quadrados e dos produtos

    \begin{aligned} S_{xx} &= \textstyle\sum (x - \bar{x})^2 = {{ c.sxx|tex:1 }} \\ S_{yy} &= \textstyle\sum (y - \bar{y})^2 = {{ c.syy|tex:1 }} \\ S_{xy} &= \textstyle\sum (x - \bar{x})(y - \bar{y}) = {{ c.sxy|tex:1 }} \end{aligned}

  3. Coeficiente

    r = \dfrac{S_{xy}}{\sqrt{S_{xx}\, S_{yy}}} = \mathbf{ {{ c.r|tex:3 }} }

  4. Teste de H₀: ρ = 0, com {{ c.graus }} graus de liberdade (n − 2)

    t = \dfrac{r\sqrt{n - 2}}{\sqrt{1 - r^2}} = {{ c.t_r|tex:2 }} \qquad {{ adocao.p_pearson|valor_p_tex }}

{# 3. Spearman #}

Troca cada valor pela sua posição (posto 1 = menor). Mede se a ordem da renda acompanha a ordem da adoção, sem exigir uma reta e sem sofrer com os condados extremos.

  1. Diferença de postos em cada condado (D maiúsculo: o d minúsculo é a diferença do teste pareado)

    D_i = \operatorname{posto}(x_i) - \operatorname{posto}(y_i) \;\Rightarrow\; \textstyle\sum D_i^2 = {{ c.soma_d2|tex:0 }}

  2. Coeficiente

    \rho = 1 - \dfrac{6\sum D_i^2}{n(n^2 - 1)} = 1 - \dfrac{6 \cdot {{ c.soma_d2|tex:0 }} }{ {{ c.n_cubo|tex:0 }} } = \mathbf{ {{ c.rho_formula|tex:3 }} }

  3. Teste de H₀: ρ = 0 ({{ c.graus }} g.l.)

    t = \dfrac{\rho\sqrt{n - 2}}{\sqrt{1 - \rho^2}} = {{ c.t_rho|tex:2 }} \qquad {{ adocao.p_spearman|valor_p_tex }}

{% if c.tem_empates %}

Há empates (posto médio): o valor exato é o Pearson aplicado aos postos, ρ = {{ c.rho|num:3 }}.

{% endif %}
{# 4. Regressão #}

Mínimos quadrados: a reta que deixa a menor soma de erros ao quadrado (a linha do gráfico).

  1. Inclinação

    b = \dfrac{S_{xy}}{S_{xx}} = \dfrac{ {{ c.sxy|tex:1 }} }{ {{ c.sxx|tex:1 }} } = {{ c.inclinacao|tex:3 }}

  2. Intercepto

    a = \bar{y} - b\,\bar{x} = {{ c.media_y|tex:2 }} - ({{ c.inclinacao|tex:3 }}) \cdot {{ c.media_x|tex:2 }} = {{ c.intercepto|tex:2 }}

  3. Reta ajustada

    \hat{y} = \mathbf{ {{ c.intercepto|tex:2 }} + {{ c.inclinacao|tex:3 }}\,x }

  4. Quanto da variação a renda explica

    R^2 = r^2 = ({{ c.r|tex:3 }})^2 = {{ c.r2|tex:2 }}

A renda explica cerca de {{ c.r2|porcento }} da diferença de adoção entre condados; o resto vem de outros fatores.
